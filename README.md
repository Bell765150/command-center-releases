# Command Center Releases

Official public release and update channel for **Command Center**.

This repository contains distributable release information and approved Windows installers only. The Command Center application source code is maintained separately in a private repository.

## Update channel

Command Center checks a small JSON manifest published from this repository to determine whether a newer version is available. Installer downloads are verified against the SHA-256 value in the manifest before the application marks an update ready to install.

## Security

Do not publish databases, backups, logs, support bundles, credentials, private configuration, or application source code in this repository.
